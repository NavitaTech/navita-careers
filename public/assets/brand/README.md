# Company brand assets

| File | What it does |
|---|---|
| `logo.svg` (or `.png`) | Your company logo, shown top-left on the attract screen and on the shareable result card. Found automatically — no code change. |
| `brand.json` | Company name, counsellor WhatsApp number, and colour overrides. Read at startup. |
| `icon-192.png`, `icon-512.png` | App icons for "Add to Home Screen". Generated by `npm run icons`; replace them with your own if you prefer. |

Colours in `brand.json` are applied as CSS variables before the first frame, so
the whole kiosk repaints. Any colour you leave out keeps its default.
